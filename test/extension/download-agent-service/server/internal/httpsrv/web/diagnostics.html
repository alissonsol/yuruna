Resolver test

Runs the vendored Fido once with the exact parameters a resolve uses. It mints a signed URL and downloads nothing, but each run spends a Microsoft session (their servers rate-ban chatty addresses), so use it to diagnose, not to poll. A successful test clears a remembered failure on the spot; a failed one re-arms it.
