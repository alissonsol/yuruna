Advanced

Pool administration. The board covers the day-to-day job — seeing how each pool is doing and giving one a ready-made test set.

  • Assign — assign a test-set to each pool (moved here from /).
  • Hosts — every host the aggregator knows, its control state and project access; move a host between pools.
  • Pools — create pools, set desiredState (run/paused/drain), add and remove hosts.
  • Test sets — the named-triple library. GH_TOKEN is never stored here.
  • Diagnostics — this daemon's own view of its dependencies.
