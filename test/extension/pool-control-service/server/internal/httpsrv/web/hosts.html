Hosts

Every host the aggregator knows. Control is the wire value: ready holds this lab's token and its clock agrees; mismatch holds a different token; skew is a clock problem; none never enrolled. Only ready hosts are auto-enrolled. Choosing a pool moves the host — a host belongs to at most one. Any column header sorts the table. Hostname is the name the host's own status page shows, and appears only once this browser is unlocked: the pool's view of a host is hostname-free, and this page renders unattended too.
