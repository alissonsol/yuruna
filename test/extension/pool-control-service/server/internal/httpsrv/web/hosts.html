Hosts

Every host the aggregator knows. Control : ready (this lab's token, clock agrees — only these auto-enroll), mismatch (different token), skew (clock problem), none (never enrolled). Choosing a pool moves the host — a host belongs to at most one. Framework and Project are the repos the host reports, linked to their source; No access means it cannot read the one configured. A re-keyed row is one machine's old identity: it was reimaged or re-cloned, so the live host answers under the id shown beside it while any pool membership stays on the old one — hand it over from that row. Hostnames appear once this browser is unlocked.
