Pools

A pool groups hosts and carries a stable Pool ID (GUID). A host belongs to at most one pool. Pool Status drives every member the way its own status page would: it reads what the members are doing now, and choosing a value applies it to each of them. Any column header sorts the table; clicking the sorted one reverses it, and Members sorts by how many there are. The leading number counts the rows as they are shown, so it stays 1…n whatever the order.
