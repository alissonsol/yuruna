Scan a network for Yuruna hosts

Every address in the network is asked whether it is running a Yuruna host status service. The ones that answer are added to the hosts this service monitors — whether or not they belong to a pool, and whether or not they ever registered with the aggregator. Scanning changes nothing on the hosts themselves.

Which network? (CIDR notation)

A network is written as an address and a prefix length: 192.168.7.0/24. The prefix length is how many leading bits the addresses share, so /24 fixes the first three numbers and scans the last one — 192.168.7.1 through 192.168.7.254, the 254 machines on that subnet. A smaller number covers more addresses (/23 is two subnets, /16 is 65,536 addresses); a larger one covers fewer (/32 is a single machine). Entering an address inside the network is fine — 192.168.7.34/24 means the same subnet as 192.168.7.0/24.
