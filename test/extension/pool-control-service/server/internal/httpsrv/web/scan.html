Scan a network for Yuruna hosts

Asks every address in the network for a Yuruna host status service and adds the ones that answer to the monitored hosts — pooled or not, enrolled or not. Scanning changes nothing on the hosts themselves.

Which network? (CIDR notation)

192.168.7.0/24 scans 192.168.7.1 through 192.168.7.254 ; a smaller prefix number covers more addresses ( /16 is 65,536), a larger one fewer ( /32 is one machine). An address inside the network means the same subnet: 192.168.7.34/24 equals 192.168.7.0/24 .
